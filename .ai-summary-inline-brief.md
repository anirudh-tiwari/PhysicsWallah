# Keep AI Summary inline with lesson date

## Objective
Ensure the AI Summary button remains on the same row as the lesson duration/date, aligned to the far right, instead of wrapping to a separate line.

## Current UI
- Existing React component: `src/pages/CourseDetail.tsx`
- Related CSS: `src/index.css`
- `.course-lesson-meta` currently allows wrapping at mobile width; the button can drop below the date/time.

## Required behavior
- Keep the duration/date group at the left and AI Summary button at the right on a single metadata row.
- Preserve the row at desktop and mobile breakpoints; adjust compact spacing/type/button sizing and available text-column width as needed.
- Avoid horizontal clipping/overflow. Keep duration/date readable and button touchable. At very narrow widths, use a compact button treatment if needed but preserve the accessible “AI Summary” name.
- Keep the metadata row anchored at the bottom of the lesson content area, aligned with the thumbnail bottom.
- Preserve existing dialog placement and interaction, lesson content, summary visibility only for Lectures.

## Constraints
- CSS-only unless impossible: update relevant styles in `src/index.css`; no content or behavior changes.
- Keep current typography and purple styling direction.
- Run `npm run build` and `npm run lint`.
