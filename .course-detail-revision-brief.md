# Course lesson card refinement

## Objective
Refine the existing course detail screen to more closely match the provided reference and user feedback. This is a real React page in the existing application; do not make a standalone mockup.

## Requested changes
- Lesson cards (`.course-lesson`) should align content to the top: lesson title starts at the same top edge as its thumbnail.
- Put the combined duration/date metadata at the bottom of the text column, aligned with the bottom edge of the thumbnail, as in `public/course-UI.jpeg`.
- Remove the lock overlay/icon from the lesson thumbnail. The lesson is not locked. Keep the purple play affordance from the reference, but do not imply an implemented media player.
- Remove all copy that identifies the screen/content as demo. The current heading “Batch Demo Videos” is demo-specific; replace that heading with “Course Content” and retain the selected course name as its subtitle. Remove any full sentence calling the screen demo/preview content. This addresses the user’s clarification that the whole sentence using demo language should go, not only the word “Demo.”
- Retain other content, the course-resource tabs, metadata, card overflow affordance, selected-course behavior, back navigation, and responsive layout.

## Visual direction
Match the clean white lesson-list reference in `public/course-UI.jpeg`: rounded white cards with subtle shadow, left-side course thumbnail, top-aligned title, date/duration anchored at thumbnail bottom, purple play affordance, and charcoal/gray system typography.

## Constraints
- Existing files: `src/pages/CourseDetail.tsx`, `src/index.css`.
- Reuse existing icons and local CSS-generated thumbnail. No new dependencies, remote media, or real playback.
- Keep keyboard/accessibility behavior for the existing resource tabs and back button.
- Ensure card alignment does not create overflow on mobile.

## Validation
Run `npm run build` and `npm run lint`.
