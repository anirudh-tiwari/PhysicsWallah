# Active / Explore tabs styled from reference

## Objective
Restyle the existing full-width Active/Explore tabs in the Batches screen to match the supplied visual reference at `/home/ashish/Documents/CodeAgent/travel/public/tabs-ui.jpeg`.

## Required appearance
- Keep the existing equal-width Active and Explore options, filling the full available content width.
- Use a pale lavender/blue rounded capsule as the shared track, with generous inset padding and a large pill radius.
- Render the selected tab as a white inset rounded pill; give its text a vivid muted purple/indigo accent. The unselected tab sits directly on the pale track with dark charcoal text.
- Apply this appearance symmetrically to either selected tab, preserving the existing Active default.
- Make the tabs comfortably touchable and polished on both desktop and mobile, scaling height/type/padding as needed without horizontal overflow.

## Preserve
- Do not alter the React tab markup or behavior, tab keyboard navigation, ARIA, panels, or selected state.
- Keep the existing app's system typography and no added dependencies/images.
- Limit implementation changes to directly related CSS in `src/index.css`.
